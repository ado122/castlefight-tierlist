How to read it

Win % when built counts every player-game where the building was constructed. It flatters late-game buildings, because you only build a legendary if the game lasts long enough and you can afford it. Win % when drafted is decided at the start of the game, so it is the fairer comparison. Both put World Freezer and Power Plant on top and Ancient of Wonders at the bottom.

The data preset uses the 95% range: S if the whole range sits above 58%, A if it sits above 50%, B if it includes 50%, C if it sits below 50%, and D for the clear worst.
