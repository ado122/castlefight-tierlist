# Castle Fight Legendary Tiers

Drag-and-drop tier list of the 14 legendary (X-tier) buildings in Castle Fight DE 9.33.
The data preset is seeded with win rates from 3,370 analyzed replays (seasons 24-25) on [castlefight.cfd](https://castlefight.cfd/unit-stats?scope=all).

Live: https://ado122.github.io/castlefight-tierlist/

Your arrangement is stored in the URL, so a copied link reproduces your list.
